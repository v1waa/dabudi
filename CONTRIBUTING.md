# Участие в разработке

Цель основной ветки — сохранять поведение восстановленной версии `2.5.8` и принимать изменения, которые можно проверить.

## Локальная подготовка

1. Установите .NET 8 SDK на Windows x64.
2. Создайте отдельную ветку от `main`.
3. Восстановите только зафиксированные зависимости:

   ```powershell
   dotnet restore .\Source\dabudi\dabudi.csproj --locked-mode
   ```

4. Соберите проект:

   ```powershell
   dotnet build .\Source\dabudi\dabudi.csproj -c Release --no-restore
   ```

5. Перед pull request выполните `publish.cmd` и вручную проверьте изменённый сценарий.

## Требования к изменениям

- не обновляйте NuGet-зависимости без отдельного обоснования: версии закреплены для точности восстановления;
- не меняйте публичные сигнатуры и ресурсы при обычном рефакторинге;
- отделяйте исправления ошибок от новых функций;
- не добавляйте сгенерированные `bin`, `obj`, `dist`, EXE и DLL;
- не добавляйте ключи, токены, персональные настройки и дампы с чувствительными данными;
- описывайте ручную проверку в pull request.

Проект не содержит полноценного автоматического набора UI-тестов, поэтому зелёная CI-сборка не заменяет проверку приложения на Windows.
