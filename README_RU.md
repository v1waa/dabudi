## Что требуется

- Windows 10/11 x64;
- .NET 8 SDK;
- либо Visual Studio 2022 с компонентом **Разработка классических приложений .NET**.

## Открытие в Visual Studio

Откройте файл `dabudi.sln`, дождитесь восстановления NuGet-пакетов и выберите конфигурацию `Release`.

## Сборка из командной строки

Самый простой вариант — запустить:

```bat
build.cmd
```

Или выполнить вручную из корня архива:

```powershell
dotnet restore .\Source\dabudi\dabudi.csproj --locked-mode
dotnet build .\Source\dabudi\dabudi.csproj -c Release --no-restore
```

Собранные файлы появятся в:

```text
Source\dabudi\bin\Release\net8.0-windows7.0\win-x64\
```

## Публикация в один EXE

Запустите:

```bat
publish.cmd
```

Готовый файл будет находиться в `dist\dabudi.exe`. Проект закреплён за теми же основными параметрами публикации, что и исходный бинарник: `.NET 8`, `win-x64`, self-contained и single-file.

## Настройки приложения

Во время работы программа хранит настройки в:

```text
%APPDATA%\dbdOverlay\settings.json
```

## Структура

- `Source/dabudi` — восстанавливаемый проект;
- `Source/dabudi/dbdOverlay` — C#-логика окон, моделей и сервисов;
- `Source/dabudi/*.xaml` — интерфейс и стили;
- `Source/dabudi/imgs` — исходные изображения;
- `Recovery` — технические материалы проверки восстановления;
- `RECOVERY_REPORT.md` — точность, проверки и неизбежные ограничения.

## Важное ограничение

Компилятор не сохраняет комментарии, исходное форматирование и часть локальных имён. Поэтому текст исходников не может быть побитово тем же, что был у автора. При этом структура приложения, все пользовательские типы и сигнатуры, ресурсы, зависимости и поведение восстановлены настолько близко, насколько позволяет управляемая сборка .NET.
