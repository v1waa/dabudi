# Проверки версии 3

Перечень функций основан на версии 2.5.8 и её восстановленных исходниках, сохранённых в истории Git. Само имя dabudi и полезные инструменты сохранены; старые слои и служебные материалы заменены.

| Функция 2.5.8 | Поведение 3.0.0 | Проверка |
| --- | --- | --- |
| Два таймера DBD | Монотонный отсчёт; 0 отключает эффект; повторный старт сбрасывает время | Регрессии и запуск оверлея в Windows |
| Секундомер | Пуск, пауза, продолжение, отдельный сброс | Детерминированные часы и запуск WPF |
| Прицел | Центр выбранного экрана, цвет и размер | Создание окна и снимок в Windows |
| Автокликер мыши/клавиатуры | 1–50 CPS, прекращение ввода после Stop, сообщение об ошибке | Проверки конкуренции с подставным источником ввода |
| Горячие клавиши | Общая регистрация, проверка дублей и защиты от синтетических команд | Регрессии правил; доступность сочетаний проверяется при регистрации |
| CPU/GPU/RAM | Фоновый опрос, необязательные температуры, независимый резерв NVIDIA | Сборка API; реальное оборудование проверяется отдельно |
| Цвета и настройки | Проверка значений, миграция, атомарная запись и резервная копия | Тесты с временными каталогами |
| Трей и автозапуск | Текущий пользователь; повторный запуск восстанавливает окно | Сборка; интеграция с рабочим столом проверяется вручную |
| Остановить инструменты | Закрываются все четыре оверлея, сбрасываются таймеры, останавливается ввод | Windows smoke-test |

## CI

`scripts/build.ps1` выполняет locked restore, Release-сборку с предупреждениями как ошибками, регрессионный набор, self-contained публикацию, проверку PE x64/GUI и версии, затем запуск опубликованного EXE на Windows.

`--smoke-test` использует отдельную папку данных, не меняет автозапуск и не отправляет реальный ввод. Он открывает все оверлеи, проверяет секундомер и общую остановку, обходит вкладки, сохраняет снимки интерфейса и фиксирует ошибки WPF binding. Этот режим не заменяет проверку конкретного GPU, игрового окна, нескольких физических мониторов и системных сочетаний на ПК пользователя.

EXE, контрольная сумма, результаты и снимки smoke-test доступны в артефактах GitHub Actions. Release повторяет те же проверки и прикладывает EXE вместе с SHA-256.

После изменения зависимостей разработчик может один раз выполнить `scripts/build.ps1 -UpdateLockFiles`, проверить изменённые lock-файлы и включить их в коммит. Обычная сборка и выпуск работают в locked mode.
