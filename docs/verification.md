## CI

`scripts/build.ps1` выполняет locked restore, Release-сборку с предупреждениями как ошибками, регрессионный набор, self-contained публикацию, проверку PE x64/GUI и версии, затем запуск опубликованного EXE на Windows.

`--smoke-test` использует отдельную папку данных, не меняет автозапуск и не отправляет реальный ввод. Он открывает все оверлеи, сверяет координаты их первого видимого кадра с якорем и проверяет отсутствие последующего скачка. Проверяются секундомер с независимым скрытием, отложенное нажатие, общая остановка, скрытие и закрытие основного окна. Отдельный процесс CPU проверяется через настоящий канал с тестовым показанием 61,5 °C, без установки драйвера и UAC; разрыв канала должен завершить этот процесс. Снимки охватывают три раздела, настройку CPU, нижние настройки оверлеев, ожидающее нажатие и минимальный размер окна; ошибки WPF binding завершают проверку неуспешно. Этот режим не заменяет проверку установки драйвера, реальных температур, игрового окна, нескольких физических мониторов и системных сочетаний на ПК пользователя.

EXE, контрольная сумма, результаты и снимки smoke-test доступны в артефактах GitHub Actions. Release повторяет те же проверки и прикладывает EXE вместе с SHA-256.

После изменения зависимостей разработчик может один раз выполнить `scripts/build.ps1 -UpdateLockFiles`, проверить изменённые lock-файлы и включить их в коммит. Обычная сборка и выпуск работают в locked mode.
