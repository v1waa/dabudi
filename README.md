# dabudi 2.5.8

Максимально близко восстановленные исходники Windows-приложения `dabudi 2.5.8`.

> [!IMPORTANT]
> Это реконструкция из предоставленного single-file EXE, а не утечка исходного репозитория. Комментарии, исходное форматирование и часть локальных имён после компиляции вернуть невозможно. Пользовательские типы, API, ресурсы, зависимости и параметры публикации восстановлены и проверены повторной сборкой.

## Что внутри

- WPF/Windows Forms-приложение на .NET 8 для Windows x64;
- 19 C#-файлов и 6 XAML-файлов;
- исходные PNG/ICO-ресурсы без перекодирования;
- оверлей Dead by Daylight, прицел, секундомер и монитор производительности;
- автокликер, горячие клавиши, трей, автозапуск и цветовая тема;
- solution для Visual Studio, фиксированный NuGet lock-файл и single-file публикация;
- GitHub Actions для автоматической сборки и выпуска EXE по тегу.

## Требования

- Windows 10/11 x64;
- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0);
- либо Visual Studio 2022 с компонентом **Разработка классических приложений .NET**.

## Быстрый старт

Откройте `dabudi.sln` в Visual Studio или выполните в корне проекта:

```bat
build.cmd
```

Ручная сборка:

```powershell
dotnet restore .\Source\dabudi\dabudi.csproj --locked-mode
dotnet build .\Source\dabudi\dabudi.csproj -c Release --no-restore
```

## Публикация одного EXE

```bat
publish.cmd
```

Готовый файл появится в `dist\dabudi.exe`. Каталог `dist` и исполняемые файлы намеренно исключены из Git: бинарные релизы следует хранить в GitHub Releases, а не в истории репозитория.

## Автоматическая сборка на GitHub

Workflow `.github/workflows/build.yml` запускается для push, pull request и вручную. После успешной сборки файл `dabudi.exe` доступен на странице запуска в разделе **Artifacts**.

Чтобы создать GitHub Release с EXE, отправьте тег:

```powershell
git tag v2.5.8
git push origin v2.5.8
```

Workflow `.github/workflows/release.yml` сам соберёт приложение и прикрепит версионный EXE к релизу.

## Структура репозитория

- `Source/dabudi` — восстанавливаемый проект;
- `Source/dabudi/dbdOverlay` — C#-логика окон, моделей и сервисов;
- `Source/dabudi/*.xaml` — интерфейс и стили;
- `Source/dabudi/imgs` — исходные изображения;
- `Recovery` — технические материалы проверки;
- `docs/GITHUB_UPLOAD_RU.md` — пошаговая загрузка на GitHub;
- `RECOVERY_REPORT.md` — методика, точность и ограничения восстановления.

Настройки запущенного приложения хранятся в `%APPDATA%\dbdOverlay\settings.json`.
