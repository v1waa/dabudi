# dabudi

Небольшое приложение для Windows 10/11 x64: таймеры Dead by Daylight, секундомер, прицел, автокликер и мониторинг системы.

**[Скачать готовый dabudi.exe](https://github.com/v1waa/dabudi/releases/latest/download/dabudi.exe)** · [Все версии](https://github.com/v1waa/dabudi/releases)

Скачайте EXE и откройте его. Установка приложения, Python и отдельная установка .NET не нужны: среда выполнения включена в один файл. Для автозапуска оставьте EXE в постоянной папке.

## Использование

- **Инструменты** — секундомер с паузой и продолжением, прицел, автокликер, CPU/GPU/RAM.
- **Dead by Daylight** — два независимых отсчёта с общим ручным запуском. `0` секунд отключает соответствующий таймер. Приложение не считывает состояние игры.
- **Горячие клавиши** — запись сочетаний, проверка конфликтов, отключение и восстановление стандартных назначений.
- **Настройки** — экран для оверлеев, перемещение мышью, цвета, размер прицела и запуск в трее вместе с Windows.

Числовые параметры и оформление применяются кнопкой **Сохранить настройки**. Клавиши сохраняются сразу; кнопки запуска таймеров и автокликера также сохраняют введённые параметры.

Закрытие основного окна оставляет приложение в трее. Двойной щелчок по значку или повторный запуск EXE открывает существующее окно. **Остановить всё** выключает все инструменты. Для завершения приложения выберите **Выход** в трее.

| Действие | По умолчанию |
| --- | --- |
| Запустить / перезапустить таймеры DBD | F9 |
| Закрыть таймеры DBD | Esc, только при открытых таймерах |
| Секундомер: пуск / пауза / продолжить | F7 |
| Сбросить и закрыть секундомер | Ctrl + F7 |
| Прицел | F8 |
| Мониторинг системы | F10 |
| Автокликер | F6 |
| Остановить все инструменты | Ctrl + Shift + F11 |
| Выход | Не назначено |

Автокликер поддерживает клавиатуру и пять кнопок мыши, 1–50 нажатий/с. Он не нажимает элементы собственного окна dabudi. Его целевая клавиша не может входить в горячую команду приложения, даже с модификаторами.

Оверлеи предназначены для оконного режима и режима без рамки. Прицел остаётся в центре полного экрана; остальные панели размещаются в рабочей области выбранного монитора. Недоступные температуры и загрузка GPU показываются как `—`. Мониторинг не запрашивает повышение прав автоматически.

## Данные

- Настройки: `%APPDATA%\dabudi\settings.json`.
- Предыдущая сохранённая версия: `settings.json.bak` рядом с настройками.
- Журнал: `%LOCALAPPDATA%\dabudi\logs`.

При первом запуске переносятся настройки 2.5.8 из `%APPDATA%\dbdOverlay\settings.json`. Старый файл не изменяется. Повреждённые файлы сохраняются отдельно до применения стандартных значений; файл от более новой версии приложения не перезаписывается.

## Разработка

C# 12 / .NET 8 / WPF. SDK закреплён в `global.json`. Откройте `dabudi.sln` в Visual Studio или используйте .NET SDK из командной строки.

```powershell
dotnet restore dabudi.sln --locked-mode
dotnet build dabudi.sln -c Release --no-restore
dotnet tests/Dabudi.Tests/bin/Release/net8.0/Dabudi.Tests.dll
dotnet publish src/Dabudi.App/Dabudi.App.csproj -c Release --no-restore -o dist
```

На Windows `build.cmd` собирает приложение и запускает регрессионные проверки; `publish.cmd` также создаёт `dist\dabudi.exe`. Полный цикл CI, включая проверку запуска WPF и EXE, выполняет `scripts/build.ps1` в PowerShell 7.

| Проект | Ответственность |
| --- | --- |
| `src/Dabudi.Core` | Таймеры, настройки, правила сочетаний, жизненный цикл автокликера |
| `src/Dabudi.Infrastructure` | Win32, датчики, JSON, журнал, автозапуск, единственный экземпляр |
| `src/Dabudi.App` | WPF, окна, состояния UI, координация инструментов |
| `tests/Dabudi.Tests` | Регрессии таймеров, ввода, миграции и сохранения настроек |

Обновления проекта публикуются в `v1waa/dabudi`, ветка `main`. Для выпуска обновляется версия в `Directory.Build.props` и `.github/release.json`; GitHub Actions проверяет соответствие версий, собирает текущий коммит и создаёт релиз `vX.Y.Z` с `dabudi.exe` и SHA-256. Поддерживается также выпуск по push тега. Опубликованные версии не перезаписываются; генерируемые бинарники не хранятся в Git.
