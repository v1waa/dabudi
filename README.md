# dabudi 2.5.8

- WPF/Windows Forms-приложение на .NET 8 для Windows x64;
- оверлей Dead by Daylight, прицел, секундомер и монитор производительности;
- автокликер, горячие клавиши, трей, автозапуск и цветовая тема;

## Требования

- Windows 10/11 x64;
- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0);
- либо Visual Studio 2022 с компонентом **Разработка классических приложений .NET**.

## Быстрый старт

Откройте `dabudi.sln` в Visual Studio или выполните в корне проекта:

```bat
build.cmd
```

Ручная сборка:

```powershell
dotnet restore .\Source\dabudi\dabudi.csproj --locked-mode
dotnet build .\Source\dabudi\dabudi.csproj -c Release --no-restore
```
